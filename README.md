# Ornn’s Forge — Champion Upgrade Picker

Standalone fan-made English web app with 168 champion recommendations. No spreadsheet access needed.

## Publish to GitHub Pages
1. Create a public repository on GitHub (for example `ornn-forge`).
2. Upload `index.html` to the root of the repository.
3. Go to Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Once GitHub has deployed the website, share the Pages URL.

Official icons load from Riot Games Data Dragon (internet connection required). The app itself is a single HTML file and needs no server. Recommendations are curated, not live patch statistics.
